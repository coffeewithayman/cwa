# Voiceprint

Clips of Ayman speaking alone, used to recognise his voice in panels and
interviews. 5–10 clips of 1–3 minutes each from different recordings
(different mics/rooms) work best. Format: `- <url or media path> <start>–<end>`.
Run `npm run enroll` after adding clips; enrolled lines get a ✅.
