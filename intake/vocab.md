# Vocabulary

Terms are fed to Whisper while transcribing and fix capitalisation afterwards.
Corrections replace mis-hearings everywhere (whole words, any case; spaces and
hyphens are interchangeable). After editing, run `npm run ingest -- --reclean`
to apply to existing transcripts without re-transcribing.
